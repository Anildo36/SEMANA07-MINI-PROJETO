### `Base Varejo`

**Curso:** Análise de Dados com Python T3
**Aluno:** Anildo Dos Santos Nascimento


## Sobre o projeto

Análise exploratória da `Base Varejo.csv`, com dados reais de comprasa no varejo. Este projeto mostra problemas como dados (nulos, duplicados, e inconsistências). Foram tratados esses problemas utilizando o pandas, e gerando assim estatísticas e junções paraa intender o comportamento de compra dos clientes.

## Arquivos do Projeto

- `analise_exploratoria_dados.ipynb` Notbook com ass análises
- `Base Varejo.csv`- Base de dados original
- `df_Limpeza_Dados.csv` - Bsse de Dados já tratadas
- `README_AnildoSantos_AnaliseDeDadosT3.md` - Instruções e insights
